# AI를 활용해 더 나은 프로덕트를 만드는 것에 관심이 많은 엔지니어입니다.

스타트업 서비스와 금융·공공기관 대상 솔루션을 개발하며 프론트엔드 개발자로 근무하고 있습니다.

현재는 프론트엔드를 기반으로 백엔드와 인프라까지 개발 영역을 확장하고 있으며,  
개인적으로 **월간 활성 사용자(MAU) 3만 이상 규모의 서비스를 혼자 개발·운영하며**  
제품 개발과 운영 전반을 직접 경험하고 있습니다.

최근에는 AI를 단순한 개발 도구를 넘어,  
제품 개발 과정과 사용자 경험을 개선하는 데 어떻게 활용할 수 있을지 관심을 가지고 있습니다.

서비스를 직접 만들고 운영하며 쌓은 경험을 바탕으로  
프론트엔드, 백엔드, 인프라 전반에 대한 기술적 이해를 넓혀가고 있습니다.

장기적으로는 여러 영역의 경험을 기반으로  
제품의 기술 방향을 주도할 수 있는 **엔지니어**로 성장하는 것을 목표로 하고 있습니다.
